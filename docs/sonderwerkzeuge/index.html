Sonderwerkzeuge.

Profilmesser, Formfräser, Stufenbohrer und weitere Werkzeuge werden nach Skizze, Zeichnung oder CAD-Daten gefertigt oder umgearbeitet.

Vom Profil zum Werkzeug.

  1. 01

    Unterlagen senden.

    Eine Skizze, Zeichnung, ein CAD-Datensatz oder ein vorhandenes Muster bildet die Grundlage.

  2. 02

    Anwendung klären.

    Werkstoff, Maschine, Bearbeitung und benötigtes Profil werden technisch eingeordnet.

  3. 03

    Fertigen oder umarbeiten.

    Je nach Aufgabe entsteht ein neues Sonderwerkzeug oder ein vorhandenes Werkzeug wird angepasst.

Konkrete Angaben helfen.

Je genauer Profil, Werkstoff und Einsatz beschrieben sind, desto gezielter kann die Anfrage geprüft werden. Das vorhandene Sonderwerkzeugformular fragt diese Angaben Schritt für Schritt ab.

Sonderwerkzeug anfragen.

Das Formular wird über Fillout geladen und an das bestehende Airtable-System übergeben. Hinweise zur Verarbeitung stehen im Datenschutz.
